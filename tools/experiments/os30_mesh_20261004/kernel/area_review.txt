Root owns and implements generic-engine32-bit lean shift, one-hot bus muxes,

Unused current program ops include STORE,ADDC,NEG,PROJ47. SUBB remains used;

general ADD/SUB instruction contract includes comparison flags.

Alternative memory packing, analysis only (no raster edits):
  Raster du/dv are16x32 arrays with the same read index. One true-dual-port
  32x32 RAM could put du at0..15 and dv at16..31, one read port per field.
  Command writes and span reads occupy separate phases; writes can reuse the
  ports with explicit address muxes. This saves one M10K with small mux cost.
  Raster u/v/count are4x16 each. If all simultaneous U/V writes share index,
  combine U/V into32bits at0..3 and count into4..7 of one true-dual-port RAM,
  using one read port per logical word. That can save two M10Ks, but requires
  checking/asserting all write callsites and preserving read latency.
  Root's MLAB conversion is simpler and already staged; consider packing only
  if its additional ALMs remain a fit blocker. Do not cut cache capacity or
  widen timing exceptions to conceal an unclosed design.
