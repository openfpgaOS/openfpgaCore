State-aware dead-slot proof, without grouping across state

The sixteen listed opcodes can be ignored by the liveness scanner in the current AJ03 build: TEXTURE, SETTIMG, GEOMETRYMODE, SETENVCOLOR, SETTILE, SETTILESIZE, LOADBLOCK, LOADTILE, LOADTLUT, SETPRIMCOLOR, SETCOMBINE, SETFOGCOLOR and the four sync opcodes. Their actual CPU handlers update renderer metadata/cache flags or are no-ops; none reads canonical vertices, materializes raw rows, flushes fog or uploads textures. SETFOGCOLOR uses this backend's explicit no-op callback. SETOTHERMODE_H/L remain barriers because their shared handler can flush deferred canonical fog.

This changes only a future dead-slot proof. The CPU still executes every state opcode, updates material/epochs/fog/cache flags and emits the same state in order. GROUP construction must still stop at all state boundaries. Existing source fences, lazy/legacy ownership and fallback/repair paths remain unchanged.

A minimal candidate can pass the immediate return_command, reject a second external return, and use a bounded local stack for nested static calls. Positive cache entries must compare exact source+return_command and must never update source-only MeshTask.dead_after. Group cache reuse must retain that proof binding. Full-frame output, canonical/fog state and exact logical command checks are mandatory before any performance or physical decision.
